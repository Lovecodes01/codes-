This is a simple React + Vite project that shows the current Indian time and date.

## Features

- Shows current Bharat (India) time
- Shows current date
- Simple and clean UI
- Built using React

## Installation

First install all dependencies:

npm install

## Run the Project

To start the project run:

npm run dev

Then open this in browser:

http://localhost:5173/

## Build Project

To create production build run:

npm run build

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
